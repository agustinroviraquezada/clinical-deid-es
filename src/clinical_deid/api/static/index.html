clinical-deid A TFM project · BIG school

Remove personal data from clinical notes before you share them.

We detect names, dates, places, IDs, contact details, ages and professions in Spanish clinical text and replace them with their category. An in-house model does the work; a language model only double-checks what the model is unsure about.

Three guarantees

Private, cautious and measured

Private by design

Your note is processed in memory and never stored or written to logs. Only metadata is recorded.

A cascade, not a black box

The model handles confident entities. Only the sentence around an uncertain one may go to the LLM. If anything fails, the entity is masked.

Measured, not promised

Every configuration is evaluated on the MEDDOCAN test set. The Comparison tab shows recall, precision, latency and cost.

How it works

Three steps, one note

  1. 01

    Paste or upload

    One note per request, up to 10,000 characters, as text or a .txt file. Nothing is stored.

  2. 02

    Detect and verify

    A RoBERTa model fine-tuned on MEDDOCAN finds personal data; uncertain entities are checked sentence by sentence.

  3. 03

    Review and take it

    Check the categories highlighted by colour, then copy the result or download it as a .txt file.

This is an academic demo. Do not paste real patient data. Your text is processed in memory only and is never stored or logged. Sentences with uncertain entities may be sent to a language model on Amazon Bedrock (EU region). Automatic de-identification can miss personal data: always review the result.

Good to know

          
Select a question to open it. Several can stay open at once.

          

            

              Can it miss personal data?
              
Yes. No automatic system is perfect, and MEDDOCAN-style case reports differ from
                real notes, so performance on real text will likely be lower. Always review the
                result before sharing it.

            

            

              What exactly is sent to the language model?
              
Only the sentence that contains an uncertain entity, never the whole note, and at
                most a fixed number of sentences per note. The model may only confirm or reject
                the entity; its answer is validated and, if invalid, the entity is masked anyway.

            

            

              Is my text stored anywhere?
              
No. The note lives in memory for the duration of the request. Logs contain only
                metadata such as length, latency and the number of entities.

            

            

              Which categories are detected?
              
NAME, DATE, LOCATION, ID, CONTACT, AGE, PROFESSION and OTHER. Any unknown type
                is still masked, as OTHER.
