[ ] clinical-deid

Spanish clinical notes · NER model + LLM cascade

Remove personal data from clinical notes before you share them.

Names, dates, places, IDs, contact details, ages and professions are replaced by their category. An in-house model does the work; a language model only double-checks the entities the model is unsure about.

Try it with an example

Built with privacy first

◇

Private by design

Your note is processed in memory and never stored or written to logs. Only metadata is recorded: length, latency and entity counts.

⇄

A cascade, not a black box

The model handles confident entities. Only the single sentence around an uncertain one may go to the LLM, which confirms or rejects it. If anything fails, the entity is masked.

≡

Measured, not promised

Every configuration is evaluated on the MEDDOCAN test set. The Comparison tab shows recall, precision, latency and cost side by side.

How it works

  1. 01

    Paste or upload

    One note per request, up to 10,000 characters, as text or a .txt file.

  2. 02

    Detect and verify

    A RoBERTa model fine-tuned on MEDDOCAN finds personal data; uncertain entities are checked sentence by sentence.

  3. 03

    Review and take it

    Check the highlighted categories, then copy the result or download it as a .txt file.

Privacy notice

This is an academic demo. Do not paste real patient data. Your text is processed in memory only and is never stored or logged. Sentences with uncertain entities may be sent to a language model on Amazon Bedrock (EU region). Automatic de-identification can miss personal data: always review the result.

Examples from the MEDDOCAN corpus (Marimon et al., 2019), licensed CC BY 4.0. Their personal data are synthetic.

Good to know

          

            Can it miss personal data?
            
Yes. No automatic system is perfect, and MEDDOCAN-style case reports differ from
              real notes, so performance on real text will likely be lower. Always review the
              result before sharing it.

          

          

            What exactly is sent to the language model?
            
Only the sentence that contains an uncertain entity, never the whole note, and at
              most a fixed number of sentences per note. The model may only confirm or reject the
              entity; its answer is validated and, if invalid, the entity is masked anyway.

          

          

            Is my text stored anywhere?
            
No. The note lives in memory for the duration of the request. Logs contain only
              metadata such as length, latency and the number of entities.

          

          

            Which categories are detected?
            
NAME, DATE, LOCATION, ID, CONTACT, AGE, PROFESSION and OTHER. Any unknown type is
              still masked, as OTHER.
